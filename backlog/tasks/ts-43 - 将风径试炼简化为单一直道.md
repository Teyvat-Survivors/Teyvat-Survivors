## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
按当前试玩反馈简化默认关卡。沿用现有客户端脚本构建，将风径试炼的玩家与怪物路线设为一条横向直道。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 默认关卡只允许沿横向直道移动，普通怪、冲锋怪及终局敌人从玩家左右两侧的同一直线上刷出，沿出生方向前进。玩家掉头、穿过怪物和击退均不会使怪物横向偏离或转身追踪。
- [ ] #2 界面呈现默认关卡直道，其他关卡保留原有移动和追踪。Lua 回归及现有千星脚本构建在 Windows CI 通过。
<!-- AC:END -->

<!-- SECTION:NOTES:BEGIN -->
本地 Lua 5.3.6 全量回归及打包脚本替身通过。直道、冲锋扫掠、击退和三个关卡完整终局均通过。
