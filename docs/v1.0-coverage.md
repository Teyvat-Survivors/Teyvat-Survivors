# 发售版 1.0 玩法对照矩阵

基线为 Steam PC 2022-10-20 Poncle 发售公告与此前已发布内容。发售补丁列的是变化，历史补丁用来确认已有玩法。当前资料列入发售日之后的条目时，以加入版本为准。下面的历史名称只用于查找证据。项目使用原创关卡布局、刷怪配置、数值表和素材，原神资源按千星奇域使用权限选用。

「确认」表示有日期的证据支持该机制在基线存在。「待复核」表示条目细节、数值或边界还需交叉验证。该矩阵建立时未验收实现，后续任务逐行更新实现状态和复现结果。
