# 千星客户端试玩接线

将构建生成的单文件 Lua 映射到官方千星沙箱。客户端脚本使用 Lua 5.3。工程先在代码库中核对，关卡存档在官方编辑器中保存和导出。

## 场景和模板

1. 在「关卡设置 → 人数设置」将必要分组的固定人数设为 1。创建界面布局，添加可见的客户端控件容器，采用深色背景。进入画布，在已有外层容器下建立铺满的内层容器 **GameRoot**。
2. 在 GameRoot 下预置两个直接子控件。**World** 是铺满 GameRoot、居于底层的容器节点。**MoveArea** 是光标检测区域，启用光标光线检测。脚本在移动端对其定位并开关，在键鼠模式隐藏此区域。
3. 在客户端控件模板中准备三种激活模板。脚本配置的数值是**根模板索引**。

| 脚本变量 | 模板根与子级 |
| --- | --- |
| `TSImageTemplate` | 根为客户端图片控件，使用官方白色圆形或相近图元。选择可着色、无点击交互的图片素材。 |
| `TSTextTemplate` | 根为客户端文本框，水平及垂直居中。 |
| `TSActionTemplate` | 根为客户端容器节点，包含 **Label**（居中的文本框）和 **Hit**（开启光标光线检测的区域）。两个子控件的锚点均拉伸至根容器四边，偏移为零。 |
| `TSConfirmAudio` | 整数，填写已配置的官方 2D 音效资源 ID。无音效填 0。 |

4. 在千星沙箱的客户端脚本资源管理器建立脚本映射，选择构建生成的 Lua 文件。创建上表四个脚本变量，把映射挂载到 GameRoot。保存后进入单人试玩。映射是随关卡打包脚本的入口。 [客户端控件与脚本](https://act.mihoyo.com/ys/ugc/tutorial/detail/mhbgxf0nynww) · [官方 Lua API](https://act.mihoyo.com/ys/ugc/tutorial/detail/mhtakr07vej4)

## 验收路径

- PC 可点击菜单，也可用数字 1–6 选当前选项。选关和初始能力后用 WASD，0 或右上角按钮切换暂停。核心角色接口可用时，初始能力页显示三个初始角色。
- 移动端在左下区域按住拖动，松手、拖出或离开页面后应停止移动。待选期间应停止战斗，点击后只应用所选项。分别选一次经验升级和宝箱奖励。
- 到达结算后点「再来一局」，验证场景复用及本局状态重置。设有效音效 ID 后确认点击时有声音。退出后不能残留输入监听和正在播放的效果。
- 保存场景并从「我的奇域 → 存档 → 导出存档」生成 `.gil`。用新槽位导入副本，分别在桌面和移动端验证画布、触控、结算及重开。记录客户端和编辑器版本。 [官方存档导入导出](https://act.mihoyo.com/ys/ugc/tutorial/course/detail/mhjuwpiubrh0)

## 本地证据和实机验收

从工程根目录运行 `lua tests/gil_client.lua`。构建后运行 `lua tests/gil_client.lua <生成的Lua文件> bundle`，验证同一套原生接口替身可启动打包脚本。测试替身驱动真实玩法核心，覆盖菜单、战斗、经验升级、宝箱、终局、重开及控件上限。实际编辑器导出、PC 与移动端交互、原生音画、保存和关卡结果信号另行验收。本脚本的结算页只呈现本局核心结果。

渲染对画布外图元做裁剪，复用已创建的显示控件，并跳过没有变化的坐标、尺寸和颜色写入。世界图片池最多 705 个，其中最多 300 个敌人。超出任一池容量时 HUD 显示提示，核心状态仍可运行。官方范围表列出 1,000 单界面组控件和 10,000 一屏控件。原生主机能承受的数量和单个 Lua 源文件大小限制尚无实测证据。 [官方编辑项范围限制](https://act.mihoyo.com/ys/ugc/tutorial/detail/mh74ae9fsg8i)
