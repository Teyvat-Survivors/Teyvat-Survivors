- 同期道具指南对 Bracelet 的说明早于发售解锁修订。进化指南把时间和材料满级写成统一规则。用发售公告和分关可进化宝箱、特殊配方证据解决冲突。 [发售日道具指南][I] [同期进化指南][E] [宝箱与配方索引][W] [发售补丁][L]
- Companion 应用部分版本发布时补录多个游戏版本，例为 0.10.0 应用记录中的 0.9.0 Bracelet 和 Gyorunton，其 Arcana 数字也有误写。以游戏公告、已达成的 Steam 成就和专题条目对齐早期版本。 [Companion 历史][AP] [0.9.0 公告][090] [Steam 公开进度][SA]
- 老正式版可获取的隐藏角色、武器、收藏条目与现代 Wiki 的 Base game 分类有差别。Tiny Bridge、Scorej-Oni、Seal、新增初始武器、后续遗物、DLC、合作模式及 Darkanas 不计入 1.0。现代角色形态进化与后续特殊武器没有计入上表。 [1.1.0 公告][N11] [武器版本索引][W] [日后 DLC][DLC] [Darkasso 公告][DARK]
