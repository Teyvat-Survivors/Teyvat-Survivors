# 项目终止决定（2026-11-21）

**项目：**《提瓦特幸存者》 / Teyvat Survivors  
**最终状态：已终止（Cancelled / Discontinued），不是暂缓或等待下一轮排期。**  
**决定：**项目所有者于 2026-11-21 明确决定放弃本项目，不继续研发、性能攻关、内容移植、测试、发版或运营。

## 决策依据

- 原目标是尽可能复刻《吸血鬼幸存者》1.0 的完整体验，包括后期密集怪潮，并能在可运行《原神》的相对低端设备上稳定运行。
- 当前性能实验中：配置 100 只时绘制 100 只；配置 300 只时绘制 300 只；配置 600 只时实际仅绘制 300 只，另 300 只被当前方案裁剪。**这证明的是当前方案的 300 绘制截断，不是千星奇域平台的硬性上限。**
- 表中的 6,000 / 18,000 次每秒位置更新，是按 60 Hz 计算的理论次数，**不是千星客户端的实测更新吞吐量或 FPS**。
- 没有足够的 PC/移动端，特别是低端手机完整战斗和持续 30 分钟的实机数据，无法验证 300 只持续移动怪物叠加碰撞、弹幕、伤害、死亡、刷新和掉落后依然流畅。离线 Lua 模拟或基准测试不能替代该证据。
- 即便采用对象池、空间分区、合并掉落、低频 AI 等成熟优化，也没有证据证明原版后期高密度体验能在目标低端设备上稳定运行。
- 项目所有者对该游戏方向的兴趣有限，不再为未知的性能上限继续投入研发资源。

## 后续处理

1. **停止执行。** 不再领取或创建开发任务；不再继续源代码移植、UI、美术、性能实验、测试、发版或推广。无需新的试验性重启提示词。
2. **冻结历史记录。** 现有源码、Backlog、测试、技术资料和计划作为归档材料保留；未完成任务视为**因项目取消而关闭的历史任务**，不得理解为可以继续自动领取的 To Do。历史版本计划不再生效。
3. **不伪造验证结果。** 本决定不是认定平台永远无法运行幸存者游戏，也不是证明千星存在 300 怪硬上限；只是当前产品目标与证据、投入意愿不匹配。
4. **仅有项目所有者明确作出新的重启决定，才能重新开放开发。** 不安排定期复查或自动恢复。
