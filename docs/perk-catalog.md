# 秘法机制与发售版对应

本切片在已有 Run 选牌链路上提供 22 张原创秘法。每局默认可重抽一次。有未展示的合法牌才消耗次数，同一来源沿用原窗口，新令牌使旧选择失效。牌组通过 `Run.enable_perks(run, { unlocked = ... })` 接入。解锁表由长期进度和客户端持有。

| 历史效果族 | 原创机制与当前边界 |
| --- | --- |
| 0 | 晶砂引火将本拍收取的经验转为玩家周围伤害。经验倍率归零，宝箱奖励仍使用原逻辑。 |
| I、X | 镜羽双编给投射攻击附加低伤回声，开弦之约在选牌后的短暂窗口增发。独立命中记录和来源标记防止回声再次触发秘法。按指定武器挑选副本与起手武器专属范围仍待细化。 |
| II | 灰羽归尘在普通投射物结束时于末端发出限频伤害，暂未接入诅咒权重。 |
| III、IV | 踏苇行印按实际位移改变冷却和暴击。春脉归契提供一次恢复生命复活，复活后的永久面板变化仍待实现。 |
| V、XVII、XVIII | 潮刻轮有时段弹速、持续时间和范围；息潮延契与舒瓣刻轴叠加等级或周期。周期和倍率为项目数值。 |
| VI | 泉心护鸣增加治疗量，并按实际非秘法治疗量激发范围伤害。派生治疗不触发后续效果。 |
| VII、XI | 折壳纹延长已有反弹与穿透，返珠长线延长已有回旋的返程。默认攻击的运动模式保持不变。 |
| VIII | 拾星罗针定时吸引最近的经验宝石，有范围及数量限制。其他地图道具暂未接入。 |
| IX、XIX | 铁枝回录加护甲，敌人实际造成伤害后进行限频反击。灰羽归尘提供另一类爆发。历史低血量及指定攻击联动仍待细化。 |
| XII、XIV | 积雪风铃定时调用现有短时减速控制，霜影留踪在击败受控敌人时于其位置触发。首领沿用控制免疫。专用投射物控制和专用掉落仍待实现。 |
| XIII | 双候时册在经验收益与伤害、冷却窗口间轮换。幸运和诅咒未纳入该卡。 |
| XV、XVI | 金蕊润息将拾币转为限频恢复。琢玉映芒提升暴击几率与暴击倍率。金币持续事件与指定攻击范围仍待细化。 |
| XX、XXI | 虚星余位按空武器位给伤害和冷却收益。回星引路结合磁吸与拾取经验激发范围伤害。 |

余烬回响保留击杀后短时强化。全部 22 张卡已绑定 Lua 进度授予，
可把 `Profile.unlocks(profile).perks` 传给 `Run.enable_perks`。客户端选牌和 PC、移动端交互待验收。

本地命令 `lua tests/perk_catalog.lua` 覆盖选项、有限重抽、触发和实战伤害。
